# P1-2: Implement image building via CLI

**Status:** open
**Depends on:** P1-1

## What to do

1. Implement `Runtime.BuildImage` in `internal/matchlock/runtime.go`.
2. Shell out to `matchlock build -f <dockerfile> -t <imageName> .` (same pattern
   as the apple runtime's `container build` call).
3. Use `os/exec.CommandContext` for cancellation support.
4. Stream build output to the provided `Writer`.
5. Return `runtime.Image{Name: imageName}` on success.
6. Write unit tests using a mock command runner (follow the apple runtime's
   `CommandRunner` pattern for testability).
