# P1-5: Implement command execution and output streaming

**Status:** open
**Depends on:** P1-3

## What to do

1. Implement `Container.Attach`:
   - Use `client.ExecStream` to run the command specified in
     `CreateContainerOptions.Args`.
   - Pass the working directory from options.
   - Wire stdout and stderr to the caller's writers (use `os.Stdout` and
     `os.Stderr` for now, matching the apple runtime pattern).
   - Store the exec result or a channel for `Wait` to read from.

2. Implement `Container.Wait`:
   - Wait for the exec started in `Attach` to complete.
   - Propagate the exit code.
   - Handle context cancellation (from SIGINT/SIGTERM): call `client.Close`
     to stop the VM gracefully.

3. Write unit tests covering:
   - Successful command execution with exit code 0.
   - Command failure with non-zero exit code.
   - Context cancellation during execution.

## Files to modify

- `internal/matchlock/container.go`

## Acceptance

A command can be executed in the sandbox with stdout/stderr streaming. Exit
codes propagate correctly. Signal handling triggers graceful shutdown.
