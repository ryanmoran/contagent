# P1-7: End-to-end validation and cleanup

**Status:** open
**Depends on:** P1-6

## What to do

1. Review all matchlock runtime code for consistency with the runtime interface
   contract. Verify that every `Container` method handles the "not yet started"
   edge case correctly.

2. Add an integration test (in `integration/` or `internal/matchlock/`) that,
   when the `matchlock` binary is available on `$PATH`:
   - Builds an image from a minimal Dockerfile (e.g., `FROM alpine:latest`).
   - Creates and starts a sandbox.
   - Runs `echo hello` and verifies stdout contains `hello`.
   - Verifies the exit code is 0.
   - Removes the sandbox and verifies it's gone.
   - Skip the test with `t.Skip` if `matchlock` is not available.

3. Run `go vet ./...` and `golangci-lint run` (if configured). Fix any issues.

4. Mark all issues in `issues/` as done.

## Files to create

- `internal/matchlock/integration_test.go` (or similar)

## Acceptance

All unit tests pass (`go test ./...`). The integration test passes when
matchlock is available. `go vet` is clean.
