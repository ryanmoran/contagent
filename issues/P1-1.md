# P1-1: Add Matchlock SDK dependency and create package skeleton

**Status:** open
**Depends on:** nothing

## What to do

1. Run `go get github.com/jingkaihe/matchlock` to add the SDK dependency.
2. Create `internal/matchlock/runtime.go` with:
   - A `Runtime` struct that satisfies `runtime.Runtime` (compile-time check).
   - Constructor `NewRuntime() *Runtime`.
   - Stub methods for `BuildImage`, `CreateContainer`, `HostAddress`, `Close`
     that return `fmt.Errorf("not implemented")` (except `HostAddress` which
     can return `""` and `Close` which can return `nil`).
3. Create `internal/matchlock/container.go` with:
   - A `Container` struct that satisfies `runtime.Container` (compile-time check).
   - Stub methods for `InspectUser`, `CopyTo`, `Start`, `Attach`, `Wait`,
     `ForceRemove` that return `fmt.Errorf("not implemented")`.
4. Verify: `go build ./...` and `go vet ./...` pass.

## Files to create

- `internal/matchlock/runtime.go`
- `internal/matchlock/container.go`

## Acceptance

`go build ./...` succeeds. Both compile-time interface checks pass. The
matchlock SDK is importable.
